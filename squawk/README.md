# Squawk AI ATC

AI air traffic control for Microsoft Flight Simulator 2024 on Xbox. Open it on a phone or tablet next to the console.

Open it at `/squawk/` on this site once GitHub Pages is turned on.

- Paste a route (like `KSAN/27 N0497F330 ZZOOO4 ... EGLL/09L`) or load from SimBrief
- Live weather, real taxiway routes from OpenStreetMap, tunable COM1 radio
- Voices: Azure (your own key, stored only on your device), Piper voice models (free download), or your phone's voices

Never put an Azure key in this repository. Paste it into Squawk's settings instead.
