# Squawk data

`firs.json`: FIR / center / oceanic boundaries and names, simplified from the
[VATSpy Data Project](https://github.com/vatsimnetwork/vatspy-data-project) (Boundaries.geojson and VATSpy.dat).
That data is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), so this file is too.
Rebuild it with `python3 tools/make_firs.py /path/to/vatspy-data-project`.
